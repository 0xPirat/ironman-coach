# Plan Adaptation & Coaching Logic — What to Do When Reality Interferes

**Purpose:** This is THE core coach skill: the plan is a hypothesis; coaching is the update loop. `what-a-coach-actually-does.md` §3 sketches the headline heuristics (never stack, convert bad weeks to recovery, neck check); this file is the **full decision system**: missed-session triage, disrupted-week playbooks (illness/travel/work-stress), **re-planning after 1 / 2 / 4+ weeks off** (detraining-aware), **plateau diagnosis**, **overreaching/overtraining off-ramps**, **motivation & adherence tactics**, and the **weekly review procedure** (what to look at, what to ask, how to set next week). Cross-references: daily readiness logic (methodology §8), PMC metrics (§7), recovery weeks (`weekly-structure-microcycles.md` §5), illness/injury return details (`injury-prevention-return-protocols.md` §6–§7).

> Evidence note: Detraining timelines and overtraining diagnosis have solid research (Frontiers detraining review; ECSS/ACSM overtraining consensus). The adaptation heuristics themselves are coaching-practice consensus — treat them as strong defaults, individualized by the athlete's data and history.

## 1. Missed Sessions — Triage Rules

Governing principles: **consistency beats any single workout; never "make up" by stacking; protect the next key session** ([Triathlete — adapt when things go wrong](https://www.triathlete.com/training/how-to-adapt-your-training-when-things-go-wrong/)).

| Situation | Rule |
|---|---|
| **1 easy/filler session missed** | Delete it. Zero compensation. |
| **1 key session missed** (long ride/run, key intervals) | Reshuffle the week to fit it in ONLY if spacing rules still hold (≥48 h between hard days, `weekly-structure-microcycles.md` §2); otherwise delete and keep the next key session intact. |
| **2–3 sessions missed in a week** | Keep the highest-priority key session, delete the rest; do NOT compress a 7-day week into 4 days. |
| **The long ride specifically** | Highest-value session for IM — move it within ±2 days if possible; a 70% version beats deletion; never do two long rides in one week to "catch up." |
| **Which to skip when forced to choose** | Sacrifice order: easy filler swim → easy run → 2nd strength → quality session → long run → long ride (last resort). |
| **Chronic misses of the same slot** (e.g. Friday swim dies every week) | That's a scheduling problem, not a discipline problem — redesign the template around real availability. |

**Anti-rule:** doubling up hard sessions to make up a missed one is how age-groupers get injured or ill; the plan's purpose is the *adaptation curve*, not box-ticking.

## 2. Disrupted Weeks — Playbooks

### 2.1 Illness
- Apply the **neck check + fever = full stop** rules and the staged return (`injury-prevention-return-protocols.md` §7). Never train through fever.
- Plan-level: **re-designate the sick week as the recovery week** of the block and shift the loading weeks; if the illness ate a loading week's quality, rewind the progression 1–2 weeks rather than resuming where the paper plan says.

### 2.2 Travel / work crunch
- **Rearrange weeks, not days:** a compromised week becomes the block's recovery week; pull the next load week forward ([Triathlete](https://www.triathlete.com/training/how-to-adapt-your-training-when-things-go-wrong/)).
- On the road: **frequency over duration** (20–40 min runs off the hotel door, hotel-gym bike, band strength) — keeps motor patterns and habit alive; accept the volume loss without guilt.
- Pre-plan around known travel: shift the long ride to before departure; treat the trip as a planned deload.

### 2.3 Life-stress spike (job, family, poor sleep)
- Stress is physiologically load: **cut intensity first, keep easy volume** (restorative, low-risk), lower the block's ambitions ([Triathlete](https://www.triathlete.com/training/how-to-adapt-your-training-when-things-go-wrong/); `what-a-coach-actually-does.md` §3.4).
- Quantify: if sleep <6 h or subjective stress high for ≥3 consecutive days → remove that week's hardest session outright.
- Communicate the reframe: "training is stress management this week, not fitness building" — protects adherence and self-image.

### 2.4 Abandon vs. compress a training block
- **Compress** (shorten a 4-wk block to 3) if ≤1 week was lost and the athlete returns healthy: keep the block's *key sessions*, drop filler, keep the deload.
- **Abandon/restart** the block if ≥2 of its weeks were compromised, or the athlete returns fatigued/ill: the block's adaptation premise is gone. Insert a clean recovery week and restart the block at a slightly lower entry point.
- **Never sacrifice the deload week to compress** — that converts a scheduling problem into an overreaching problem.
- Near the race: specificity wins — if the final 8 weeks get disrupted, protect race-specific long sessions and taper timing; drop ceiling-raising intensity first.

## 3. Re-Planning After Time Completely Off

Detraining physiology (see `injury-prevention-return-protocols.md` §6.2; [Frontiers detraining review](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2023.1334766/full)): plasma volume and stroke volume fall first; **measurable aerobic decline starts ~day 10; VO2max −4–14% by 2–4 weeks; ~10% by 5 weeks; up to ~20% by 8+ weeks**; long-trained athletes retain more.

| Time off | Fitness reality | Re-entry rule |
|---|---|---|
| **≤1 week** | Essentially nothing lost (may even be fresher) | Resume plan where it stands; maybe soften the first quality session; no restructuring |
| **2 weeks** | Small aerobic dip, feel worse than you are | Rewind the plan **2 weeks**; first week back at ~70% volume, intensity one zone down; normal by week 2–3 |
| **3–4 weeks** | VO2max −6–12%; muscular endurance eroding | Rewind **3–4 weeks**; 1 week easy aerobic re-entry (~50–60% volume), then rebuild ~10%/wk; reintroduce intensity in week 2–3; re-test zones after ~3 weeks (`testing-zones-benchmarking.md`) |
| **4–8+ weeks** | Substantial loss; zones stale; tissues deconditioned | **Mini re-base:** 2–4 weeks aerobic + strength AA before any quality; re-test all zones; re-plot the season — if the A race is <12 weeks away, reassess the goal honestly (finish-focused pacing, or defer) |

Rules of thumb: **rebuild takes roughly 1–2× the time off** to return to prior level; volume returns before intensity; run volume returns *slowest* (tissue risk — ACWR spike, `injury-prevention-return-protocols.md` §2).

## 4. Plateau Diagnosis & Response

Definition: key metrics (FTP, threshold pace, CSS, race results) flat for **8+ weeks despite consistent training**. Diagnose before prescribing ([2peak — plateau effect](https://blog.2peak.com/en/plateau-effect-7-ways-to-overcome-training-stagnation-in-endurance-sports/), [Marathon Handbook](https://marathonhandbook.com/workout-plateau/)):

**Diagnostic checklist (in order):**
1. **Is it real?** Rule out a bad test day (fatigue, heat, fuel — `testing-zones-benchmarking.md` §7) and check whether *durability* improved even if peak numbers didn't (for IM, durability IS the goal).
2. **Monotony:** same sessions for months → body fully adapted. Fix: rotate stimulus (SS↔threshold↔over-unders; tempo↔hills — `workout-library-session-design.md` §6).
3. **Intensity blur:** easy days too hard, hard days too soft (the classic). Fix: re-polarize — enforce true Z1–Z2 on easy days, make quality genuinely at target.
4. **Under-recovery:** sleep, life stress, no real deloads. Fix: recovery week now; audit sleep (`recovery-sleep-rest.md`).
5. **Under-fueling:** chronic low energy availability caps adaptation (RED-S — `nutrition-deep-dive.md` §7). Fix: fuel the work.
6. **Under-loading:** genuinely too little stimulus (rare in motivated athletes, common in the time-crunched). Fix: add one quality session or extend the long sessions.
7. **Wrong lever for the sport:** swim plateaus are usually *technique*, not fitness — video analysis beats more meters.

**Response protocol:** change **one** lever, give it a 4–6-week block, re-test. If two consecutive interventions fail AND fatigue markers worsen → treat as possible non-functional overreaching (§5), not a training-design problem.

## 5. Overreaching → Overtraining: Diagnosis and Off-Ramps

The spectrum (ECSS/ACSM joint consensus — [Meeusen et al. 2013](https://pubmed.ncbi.nlm.nih.gov/23247672/); [Overtraining Syndrome: a practical guide, PMC3435910](https://pmc.ncbi.nlm.nih.gov/articles/PMC3435910/)):

| State | Performance dip lasts | Verdict |
|---|---|---|
| **Functional overreaching (FOR)** | days–2 weeks, then supercompensation | Planned/acceptable (end of a load block) |
| **Non-functional overreaching (NFOR)** | weeks–months | Mistake — intervene now |
| **Overtraining syndrome (OTS)** | >2 months, systemic symptoms | Season-threatening — medical work-up |

**Diagnosis is by exclusion + pattern:** there is **no single biomarker**. The practical toolkit: performance tests (a standard workout getting *slower* at the same HR/power), persistent HRV suppression + elevated RHR (methodology §7.3), mood disturbance (POMS-style — irritability, depression, "dread of training"), sleep disruption despite exhaustion, recurrent illness/niggles (`recovery-sleep-rest.md` §4; `what-a-coach-actually-does.md` §6). **FOR feels like normal heavy-training tiredness; NFOR adds mood/motivation collapse.**

**Off-ramps (act early, act big):**
- **Suspected NFOR:** immediately cut to **7–14 days of easy-only** (30–60 min Z1, or full rest), sleep priority, fuel up. Then re-test with a standard benchmark session. If performance and mood rebound → resume at reduced load (start the next block one notch lower, switch 3:1 → 2:1 loading).
- **No rebound after ~2 weeks easy** → extend rest, strip all intensity for another 2–4 weeks, screen for confounds (iron/ferritin, thyroid, RED-S, infection) with a physician.
- **Rule for the AI coach:** two of {suppressed HRV ≥5–7 days, RHR +5 bpm sustained, benchmark session degraded, athlete language showing dread/flatness} → force a recovery intervention, even mid-block. Losing 1–2 weeks to caution is cheap; NFOR costs 2+ months.

## 6. Motivation Dips & Adherence Tactics

Consistency is the whole game over 18 months ([Triathlete — dear coach, consistency](https://www.triathlete.com/training/dear-coach-how-do-i-ensure-my-training-is-consistent), [Better Triathlete — consistency](https://bettertriathlete.com/training/consistency-the-key-to-success/); goal frameworks in `mental-psychological-coaching.md` §3):

- **Diagnose the dip:** physical fatigue masquerades as motivation loss — check HRV/sleep/load first. If body is fine, it's psychological (boredom, life stress, goal distance).
- **Shrink the commitment:** "10-minute rule" — start the session, permission to stop after 10 min (almost nobody stops). A short session maintains the *habit*, which matters more than the TSS.
- **Reconnect to the why:** revisit the athlete's stated reason (from intake, `what-a-coach-actually-does.md` §1); reframe the week's purpose in plain language.
- **Inject variety and novelty:** new routes, group ride/swim squad, a swap (MTB, trail run) for a filler session; a mid-build C-race for spark.
- **Make the plan visibly realistic:** athletes abandon plans that assume ideal life. Cut the plan to what fits; "consistency beats perfection."
- **Accountability structures:** training partners, publicly stated goal, streak metrics, weekly review ritual (§7). An AI coach's daily check-in *is* the accountability mechanism — use it.
- **Process goals in dips:** during a motivation trough, score the athlete on completion/showing-up, not on paces.
- **Planned "life weeks":** 1–2 weeks per season deliberately unstructured (maintain 3–4 fun sessions) prevent the deep burnout hole; better scheduled than forced.
- **Watch the language** for the burnout signature (dread, flatness — §5 and `what-a-coach-actually-does.md` §6): a motivation dip + physical red flags is NFOR, not laziness.

## 7. The Weekly Review — How a Coach Sets Next Week

The core ritual (run every 7 days; [TrainingPeaks — coach's guide to ATL/CTL/TSB](https://www.trainingpeaks.com/coach-blog/a-coachs-guide-to-atl-ctl-tsb/), [Scientific Triathlon — data-driven training](https://scientifictriathlon.com/data-driven-triathlon-training/)):

### 7.1 What to look at in the data
1. **Compliance:** planned vs completed (sessions, duration, intensity). <70% completion for 2+ weeks = the plan is wrong for this life, not the athlete failing.
2. **PMC:** CTL trend (ramp ≤~5–7/wk), ATL, TSB (flag sustained <−20 to −30) — methodology §7.
3. **Intensity distribution:** did easy stay easy? (time-in-zone check — the most common silent failure).
4. **Key-session quality:** were interval targets hit? Decoupling (HR drift vs power/pace) on long sessions trending down = aerobic progress.
5. **Morning metrics trend:** HRV baseline, RHR, sleep hours (methodology §7.3, §8).
6. **Body:** niggle reports, pain scores (`injury-prevention-return-protocols.md` §4–§5).

### 7.2 What to ask the athlete (subjective beats objective when they conflict)
- "How did the week feel overall, 1–10?" · "Which session felt best / worst, and why?"
- "How's sleep? How's life stress (work/family) next week?"
- "Any niggles, anywhere, even small ones?" · "How's appetite and fueling been?"
- "Looking at next week's plan — what's realistic? What's in the calendar I should know about?"
- Open question, always: "Anything else I should know?" (this surfaces what the data can't — `what-a-coach-actually-does.md` §6).

### 7.3 Deciding next week (decision order)
1. **Safety screen first:** illness/injury/overreaching flags → apply §2/§5 and `injury-prevention-return-protocols.md`; everything else waits.
2. **Calendar screen:** fit the template to next week's real availability (`weekly-structure-microcycles.md` §6).
3. **Load decision:** if the week was completed well and markers are green → progress one notch (per block plan). If partially completed or amber → repeat the week's level (don't progress). If red → recovery week now, regardless of where the block "should" be.
4. **Session-level tweaks:** rotate any stale stimulus; schedule tests if due (`testing-zones-benchmarking.md` §5); place the key sessions first, filler last.
5. **Communicate the why** in 2–3 sentences — athletes comply with plans they understand ([TrainingPeaks coach guide](https://www.trainingpeaks.com/blog/trainingpeaks-guide-for-coaches/)).

## If-Then Rules Summary

- IF one session is missed → THEN delete it (easy) or reshuffle only if spacing holds (key); never stack; protect the next key session.
- IF forced to cut a week down → THEN sacrifice in order: filler swim → easy run → 2nd strength → quality → long run → long ride.
- IF the same session dies every week → THEN redesign the weekly template around real availability.
- IF a whole week is disrupted (travel/illness/work) → THEN re-designate it as the block's recovery week and shift load weeks; on the road, keep frequency with short sessions.
- IF life stress spikes (≥3 days of poor sleep/high stress) → THEN cut intensity first, keep easy volume, and remove the week's hardest session.
- IF ≥2 weeks of a block were compromised or the athlete returns fatigued → THEN abandon and restart the block lower; never delete the deload to compress.
- IF time off = ≤1 wk → resume; 2 wk → rewind 2 wk, first week ~70%; 3–4 wk → rewind 3–4 wk, easy re-entry week, re-test in ~3 wk; >4 wk → mini re-base (2–4 wk aerobic+AA), re-test all zones, reassess the race goal if <12 wk out.
- IF rebuilding after time off → THEN volume before intensity, run volume slowest, total rebuild ≈1–2× the time off.
- IF metrics are flat ≥8 weeks → THEN diagnose in order (bad test? monotony? intensity blur? under-recovery? under-fueling? under-loading? technique?), change ONE lever, re-test after 4–6 weeks.
- IF two of {HRV suppressed ≥5–7 d, RHR +5 sustained, benchmark degraded, dread/flat language} → THEN force 7–14 days easy-only now; no rebound after 2 weeks → strip intensity 2–4 more weeks and refer for medical screen (iron, thyroid, RED-S).
- IF motivation dips with green physical markers → THEN 10-minute rule, variety, reconnect the why, process goals, accountability; IF with red markers → THEN treat as overreaching, not laziness.
- IF running the weekly review → THEN check compliance → PMC → intensity distribution → key-session quality → morning metrics → niggles; ask feel/sleep/stress/niggles/calendar; then decide: green = progress, amber = repeat, red = recover — and always explain the why.
- IF plan completion <70% for 2+ weeks → THEN shrink the plan to fit the athlete's life; consistency beats perfection.
