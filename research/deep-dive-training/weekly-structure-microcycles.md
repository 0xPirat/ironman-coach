# Weekly Structure & Microcycles — Laying Out the Training Week

**Purpose:** The methodology file gives the macro shape (18-month periodization, weekly hours, intensity distribution — `ironman-training-methodology.md` §1, §11) and the session catalog lives in `workout-library-session-design.md`. This file is the **week-assembly layer**: concrete weekly templates for a **time-constrained age-grouper (~8–14 h/week)** in each phase, the **sequencing rules** (which sessions must not collide, how to space key sessions, where strength goes), **loading-block structure** (3-week vs 2-week), **recovery-week design**, handling a **weekend-heavy schedule**, and how the week **changes with distance-to-race**.

> Evidence note: Weekly templates are coaching-practice convention (TrainingPeaks plans, MyProCoach, 80/20 Endurance, Roadman, Scientific Triathlon). Interference/sequencing rests on the concurrent-training evidence summarized in methodology §5. Individual constraints (work, family) always override a template.

---

## 1. The Building Blocks of a Triathlon Week

A well-formed week for a full-IM age-grouper contains, in rough priority order:
1. **Long ride** (the single biggest fitness driver for IM) — weekend.
2. **Long run** — weekend (opposite day to the long ride) or midweek if weekend is bike-heavy.
3. **1–2 key quality sessions** (bike threshold/SS, run tempo/threshold) — midweek.
4. **A brick** (bike→run) — usually weekend, attached to the long ride in build/peak.
5. **2–3 swims** (at least one CSS/quality, one aerobic/technique) — flexible, low residual fatigue.
6. **1–2 strength sessions** — placed to protect running.
7. **Easy aerobic "filler"** to hit volume and the 80% easy target.
8. **≥1 full rest day** (non-negotiable for age-groupers with jobs).

**Frequency guide by sport** (methodology §11): swim 2–3×, bike 3–4×, run 3–4×, strength 1–2×.

## 2. Sequencing Rules (what must not collide)

These are the coach's hard constraints; the template is built around them ([concurrent-training evidence, methodology §5](#); [Roadman IM bike plan](https://roadmancycling.com/blog/ironman-bike-training-plan-16-weeks)):

1. **Never put two key/hard sessions back-to-back without ≥1 easy or rest day between**, unless deliberately creating a "hard block" (advanced, build only). Space hard days ~48 h apart.
2. **Strength (esp. Max Strength / heavy legs) does NOT go the day before a key run or long run.** Best: same day *after* the run (or ≥6 h later), or on an easy-run day. Lower-body lifting the day before a quality run blunts it and raises injury risk (interference + residual fatigue).
3. **Long run and long ride on separate days** where possible. If forced onto the same weekend, ride Saturday / run Sunday (or vice-versa) with the brick attached to the ride day — never a standalone long run the day after the long ride *plus* a brick.
4. **Hard bike and hard run separated** — a threshold bike and threshold run on the same day (or consecutive days) overloads the legs. If combined, do the higher-priority one first while fresh.
5. **Swim can go almost anywhere** — low leg fatigue, so it's the "filler" that fits around bike/run. A hard CSS swim the morning of a key bike is usually fine; avoid stacking a max shoulder/swim session right before an important open-water session.
6. **Brick run goes right off the bike**, and the brick's bike portion counts as that day's ride — don't also schedule a separate hard ride.
7. **Recovery/rest day placement:** typically Monday (after the big weekend) and/or a mid-week easy day. At least one true rest day per week for age-groupers.

**Priority when compressing:** protect long ride → long run → key quality → brick; sacrifice easy filler swims/runs and one strength session first (see `plan-adaptation-coaching-logic.md` §1).

## 3. Weekly Templates by Phase (time-crunched, ~8–14 h)

Assumes weekday sessions capped ~60–75 min, weekend is where volume lives (a realistic working-athlete constraint — [TrainingPeaks 8–10 h base/build plan](https://www.trainingpeaks.com/training-plans/triathlon/tp-52326/base-build-plan-8-10-hours-per-week)). Adjust to the athlete's actual free days.

### 3.1 BASE week (~8–11 h) — aerobic volume, technique, strength foundation
| Day | AM | PM |
|---|---|---|
| Mon | — (rest) | Strength (AA/MS) 35 min |
| Tue | Swim technique/CSS 45–60 min | — |
| Wed | Bike Sweet Spot 60–75 min | (opt. easy run 20–30 min) |
| Thu | Run easy + strides 45 min | Strength 35 min |
| Fri | Swim aerobic/technique 45 min | — |
| Sat | **Long ride Z2 2.5–4 h** | (short brick run 15 min opt.) |
| Sun | **Long run Z2 60–90 min** | — |

- Intensity: ~1–2 quality sessions (SS bike, strides); rest aerobic. ~85% easy.

### 3.2 BUILD week (~10–13 h) — race-specific intensity, bricks
| Day | AM | PM |
|---|---|---|
| Mon | — (rest) | Strength maintenance 30 min |
| Tue | **Bike threshold/over-unders 60–75 min** | Swim CSS 45 min |
| Wed | Run easy 45 min | — |
| Thu | **Run tempo/threshold 60 min** | Strength 30 min (after run) |
| Fri | Swim aerobic 45–60 min | — |
| Sat | **Long ride w/ race-power blocks 3.5–5 h → brick run 20–45 min** | — |
| Sun | **Long run w/ race-pace finish 90–130 min** | — |

- Two–three quality sessions; long ride carries race-power work; brick attached to ride.

### 3.3 PEAK / race-specific week (~11–14 h) — specificity, durability
| Day | AM | PM |
|---|---|---|
| Mon | — (rest) | easy swim 30 min opt. |
| Tue | **Bike race-power intervals 75 min** | Swim CSS 45 min |
| Wed | Run easy 45–60 min | Strength maintenance 25 min |
| Thu | **Run IM-pace tempo 60–70 min** | — |
| Fri | Swim OW-skills / aerobic 45 min | — |
| Sat | **Long ride @ IM effort 4.5–6 h → brick run 45–75 min @ IM pace** | — |
| Sun | Long-ish run 100–140 min (easy) | — |

- The "Big Day" race-sim replaces the Sat/Sun combo ~9 and ~4 weekends out (see `workout-library-session-design.md` §7, `race-preparation-logistics.md` §5).

### 3.4 TAPER week (final 2–3 wk; see methodology §10)
- **Volume down 40–60%, keep intensity/frequency.** Short race-pace "openers": e.g. bike 3×3 min @ 90%, run a few IM-pace pickups, swim 4–6×100 @ CSS. One full rest day + easy days; sharpen, don't build. Race-week: very light, legs-opener 2 days out.

## 4. Loading Blocks: 3-Week vs 2-Week

- **Classic 3:1** — three progressive loading weeks then one recovery week (methodology §7.4, §1.2). Default for most age-groupers; matches monthly rhythm.
- **2:1** — two loading weeks, one recovery. Use for **older athletes (40+), beginners, high life-stress, or when HRV/fatigue markers deteriorate faster than expected.** Safer, slightly less total load.
- **Undulating within the block:** each loading week nudges the key sessions up one notch (reps→duration→density, per `workout-library-session-design.md` §6). E.g. Wk1 3×10 min threshold, Wk2 4×10, Wk3 3×12; Wk4 deload.
- **Ramp-rate guardrail:** keep CTL growth ≤ ~5–7 TSS/day/week; back off if TSB stays below −25 to −30 or feel/HRV degrades (methodology §7.2–§7.3; [TrainingPeaks ATL/CTL/TSB](https://www.trainingpeaks.com/coach-blog/a-coachs-guide-to-atl-ctl-tsb/)).
- **Decision rule:** if the athlete can't complete the Wk3 (peak) key sessions at target, the block was too aggressive → shorten to 2:1 next cycle.

## 5. Recovery-Week Design (the week that makes the training work)

A recovery week is **planned adaptation, not lost training** (methodology §7.4; `recovery-sleep-rest.md` §3):
- **Volume −40 to −50%** vs the prior loading week; **keep frequency and a touch of intensity** (short openers) so you don't go flat — full rest for a week detrains and feels worse.
- **Cut the long sessions most** (drop the long ride/run ~40–50%); keep some short quality to maintain sharpness.
- **Purpose:** absorb load, let TSB rise back toward 0 to +5, refresh mentally, catch up on sleep/life.
- **Signals it worked:** HRV/RHR normalize, motivation returns, legs feel "springy" by end of week. If not, extend recovery 2–4 more days before the next loading week.
- **Retest** benchmarks in/after a recovery week when fresh (see `testing-zones-benchmarking.md` §5).

## 6. Handling a Weekend-Heavy / Working-Athlete Schedule

Reality for most: long sessions only fit Sat/Sun; weekdays are short.
- **Anchor the two biggest sessions to the weekend** (long ride Sat, long run Sun) and build the week backward around them.
- **Front-load quality midweek** (Tue/Thu) so there's an easy or rest day before the weekend's long ride — arrive at the key volume day fresh.
- **Double-day only when necessary and only if one is easy** (e.g. AM swim + PM easy run). Never two hard doubles in a day for a time-crunched athlete.
- **If only one weekend day is free:** stack a long ride → brick run that day; move the long run to a weekday evening or accept a shorter long run. A ride-Saturday, off-Sunday pattern (or vice-versa) is fine.
- **Commute training** (run/ride to work) is legitimate aerobic volume — count it.
- **Protect one true rest day** even in a busy week; skipping it to "catch up" is how age-groupers dig holes.
- **Contingency slack:** assume ~1 week in 4 gets partly disrupted; a good template has a droppable filler session, not a maxed-out 14 h every week (see `plan-adaptation-coaching-logic.md` §2).

## 7. How the Week Changes with Distance-to-Race

| Time to race | Week character | Long ride/run | Intensity | Bricks | Specificity |
|---|---|---|---|---|---|
| **>26 wk (early base)** | Volume + technique + strength MS | building | strides/SS only | short/optional | general |
| **16–26 wk (late base)** | Aerobic volume peaks; add threshold | growing | 1–2 quality | short weekly | rising |
| **8–16 wk (build)** | Race-specific intensity, long bricks | near-max long | 2–3 quality | key weekly brick | high |
| **4–8 wk (peak)** | Longest race-specific days, Big Day sims | max durability | race-power focus | IM-pace bricks | maximal |
| **2–3 wk (taper)** | Volume ↓ 40–60%, keep intensity | short | short openers | none/short | maintain feel |
| **Race week** | Minimal; sharpen + logistics | none | 1–2 openers | none | rest |

Rules of thumb:
- **Volume peaks ~3–4 weeks before the race**, then taper. The single longest ride/run and the last Big Day land ~4 weekends out.
- **Intensity is highest in build, not peak** — peak is about race-specific *durability* and pacing, not raising the ceiling.
- **Strength shifts** from Max-Strength (base) → power/maintenance (build) → minimal/none (final 2 weeks) (methodology §6.4).

## If-Then Rules Summary

- IF assembling a week → THEN place long ride and long run on separate weekend days, put 1–3 quality sessions midweek with ≥48 h between hard days, and guarantee ≥1 full rest day.
- IF scheduling strength → THEN never the day before a key/long run; prefer same-day-after-run or an easy-run day; drop to maintenance in build and to near-zero in the final 2 weeks.
- IF two hard sessions would land back-to-back → THEN insert an easy/rest day between them (unless a deliberate advanced hard-block).
- IF combining long ride + long run in one weekend → THEN attach the brick to the ride day and never stack a standalone long run the day after ride+brick.
- IF the athlete is a beginner / 40+ / high-stress / fatigue markers degrade fast → THEN use a 2:1 loading block instead of 3:1.
- IF a recovery week → THEN cut volume 40–50% (mostly from long sessions), keep frequency + short openers; extend it if HRV/RHR/motivation haven't recovered.
- IF weekend-only long sessions → THEN anchor the two biggest sessions to the weekend and front-load quality midweek so you arrive fresh.
- IF >6 months out → THEN volume + technique + Max-Strength; IF 8–16 weeks out → THEN race-specific intensity + bricks; IF <4 weeks → THEN peak durability then taper (volume −40–60%, keep intensity).
- IF CTL is climbing >~5–7 TSS/day/wk or TSB sits below −25/−30 → THEN cap the ramp and/or shorten the loading block.
- IF the week can't be completed as written → THEN protect long ride → long run → key quality → brick, and sacrifice filler + one strength session first.
