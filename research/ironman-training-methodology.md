# Ironman Training Methodology — Evidence-Based Reference for a Hybrid Amateur Athlete

**Purpose:** Reference document for a local Mac coaching app. Athlete goal: complete a full-distance Ironman (3.8 km swim / 180 km bike / 42.2 km run) over an ~18-month horizon, as a beginner-to-intermediate, while maintaining serious strength training (hybrid athlete). Athlete uses heart-rate zones and a **Garmin Forerunner 965**.

**How to use this doc:** Sections 1–12 give the science and practice. The final **"Coaching Rules Summary"** distills everything into if-then logic an AI coach can follow directly. Tables are designed to be machine-readable.

> Note on sources: Several recommendations (especially Ironman-specific tapering and very-long-event physiology) are extrapolated from shorter-distance research and coaching consensus — there is limited RCT-level evidence for 140.6 specifically. Where this matters, it is flagged.

## 1. Periodization Model — 18-Month Ironman Build

### 1.1 The hierarchy (Friel / Bompa lineage)

| Term | Duration | Definition |
|---|---|---|
| **Macrocycle** | The whole season (here ~18 months, split into 2 annual cycles) | Full progression from general → specific fitness, peaking at the A-race |
| **Mesocycle / Period** | 3–8 weeks (a "block") | Prep, Base, Build, Peak, Race, Transition — each emphasizes a fitness quality |
| **Microcycle** | Usually 1 week (6–10 days possible) | The repeating training week, structured as load weeks + a recovery week |

The core philosophy (Friel, *The Triathlete's Training Bible*): start with **generalized** training and move toward **race-specific** training as the A-race approaches, arranging workouts so qualities built early are *maintained* while new ones are added.

### 1.2 The periods

| Period | Focus | Typical length per block |
|---|---|---|
| **Prep** | Re-introduce training, movement quality, build a base of strength | 2–4 wk |
| **Base** | Aerobic endurance (Zone 2), swim technique, max-strength in gym, durability | 3–4 wk blocks |
| **Build** | Race-specific intensity: sub-threshold/threshold bike & run, brick work | 6–8 wk |
| **Peak** | Highest race-specific load, longest sessions, sharpening | 2–4 wk |
| **Taper/Race** | Shed fatigue, hold fitness, arrive fresh | 2–3 wk |
| **Transition** | Active recovery between annual cycles / after race | 1–4 wk |

### 1.3 Phasing 18 months for a beginner-to-intermediate

An 18-month runway is a luxury — it lets you treat **Year 1 as foundation** (durability, technique, no rush) and **Year 2 as the targeted build** to the A-race. Suggested macro-structure (assuming A-race at ~month 18):

| Months | Macro-phase | Primary goal | Hours/wk (typical) |
|---|---|---|---|
| 1–3 | **Foundation Base 1** | Aerobic base, learn to swim properly, gym max-strength, run durability | 6–9 |
| 4–6 | **Foundation Base 2 + first B-race** | Extend Z2 volume, do a sprint/Olympic tri as a skills test | 7–10 |
| 7–9 | **Transition + Base 3** | Short recovery block, then biggest pure-aerobic base | 8–11 |
| 10–12 | **Build 1 + 70.3 (C/B-race)** | Race-specific intensity; race a 70.3 as a rehearsal | 9–13 |
| 13–15 | **Base refresh → Build 2** | Re-base briefly, then full Ironman-specific build | 10–14 |
| 16–17.5 | **Peak** | Longest rides/runs, biggest bricks, race-day simulation | 12–16 |
| Final 2–3 wk | **Taper → Race** | Reduce volume 40–60%, hold intensity | 4–7 |

Key principles for the beginner-to-intermediate:
- **Durability before intensity.** Spend Year 1 building tissue tolerance (especially for running) and swim technique. Most first-timer failures are injury and swim panic, not lack of fitness.
- **Race into form.** Use a sprint/Olympic (month ~5) and a 70.3 (month ~11) as B/C-races — they validate pacing, nutrition, and transitions without derailing the plan.
- **3:1 or 2:1 load:recovery** microcycle rhythm throughout (see §7).

*Sources: [Joe Friel — Build Period](https://joefrieltraining.com/build-period-overview/), [Coach Ray — Friel periodization](https://www.coachray.nz/2021/10/18/joe-friels-bible-for-periodisation/), [MyProCoach — Triathlon periodization](https://www.myprocoach.net/blog/triathlon-periodization/), [TrainingPeaks — Annual Training Plan](https://www.trainingpeaks.com/learn/articles/the-comprehensive-guide-to-creating-an-annual-training-plan/)*

## 2. Polarized vs. Pyramidal Training (80/20)

### 2.1 The principle

Stephen Seiler (Univ. of Agder) **measured** what elite endurance athletes across running, cycling, rowing, and XC-skiing actually do: roughly **80% of sessions/time at easy intensity (Zone 1–2)** and **~20% at high intensity (threshold and above)**, with **very little time in the "grey zone"** between. He didn't invent it — he documented it.

- **Polarized:** lots of easy + some very hard, **little moderate**. Distribution by session count is often ~80/0/20 (easy/moderate/hard) or by time ~75–80 / 5 / 15–20.
- **Pyramidal:** lots of easy, a moderate amount of threshold, a little high-intensity (easy > threshold > VO2). More threshold than polarized.

Evidence: Stöggl & Sperlich (2014) RCT found **polarized blocks** produced larger gains in VO₂max and time-to-exhaustion than threshold-heavy or pure high-volume blocks.

### 2.2 Why most volume should be Zone 2

- Z2 builds the aerobic engine: mitochondrial density, capillarization, fat oxidation, stroke volume — the qualities an Ironman is won on — **at low recovery cost**, so you can repeat it day after day.
- The amateur's classic error is riding/running easy days **too hard** ("grey zone"), accumulating fatigue faster than adaptation, blunting the truly hard sessions and the long sessions.

### 2.3 Practical distribution & where hard work goes

| Phase | Easy (Z1–Z2) | Threshold/Hard (Z3–Z5) | Distribution style |
|---|---|---|---|
| Base | 85–90% | 10–15% | Polarized → pyramidal-leaning |
| Build | 75–80% | 20–25% | Pyramidal (more sub-threshold/threshold, race-specific) |
| Peak | 80% | 20% | Polarized again, race-pace specific |

**Placement of hard sessions:** 2 (max 3) quality sessions/week total across all three sports — never stack quality on consecutive days for an amateur with a job. Keep ~48 h between hard sessions for the *same* muscle group. The long ride and long run are "easy" by intensity but are themselves the week's big stressors — treat them as key sessions.

A practical, full-distance interpretation: an Ironman is largely an **aerobic/Z2 event**, so the *amount* of true high-intensity is modest; the 20% should bias toward **sub-threshold and threshold** (race-relevant) rather than maximal VO₂ work, especially in Build.

*Sources: [Roadman — Seiler 80/20](https://roadmancycling.com/blog/stephen-seiler-80-20-polarised-training-cyclists), [TrainingPeaks — Does Polarized Training Work?](https://www.trainingpeaks.com/blog/does-polarized-training-really-work/), [FastTalk Labs — Polarized Training pathway](https://www.fasttalklabs.com/pathways/polarized-training/), [Outside — Polarized debate](https://www.outsideonline.com/health/training-performance/polarized-training-debate/)*

## 3. Sport-Specific Progression Rules

### 3.1 Run — the highest injury-risk discipline

**Volume progression — the 10% rule and its limits:**
- The classic "increase weekly mileage ≤10%" is a useful *default guardrail*, not a law. An RCT found novices progressing **~24%/wk** did not show elevated injury risk, so the 10% figure is conservative.
- **More important finding (BJSM, ~5,200-runner cohort):** the danger is **single-session spikes**, not weekly totals. Increasing one run >10% beyond your longest run in the prior 30 days raised overuse-injury risk substantially (small spike +64%, moderate +52%, large spike >2×). **Rule: cap the long run's growth relative to the recent longest run, not just weekly mileage.**

**Injury-risk management (Achilles, shin, knee, hip, back):**
- **Progress long run conservatively** (≤~10% over recent longest); insert a down-week every 3rd–4th week.
- **Run-walk** (e.g., Galloway) for beginners and during early base: structured walk breaks (e.g., run 4–9 min / walk 1 min) reduce peak tissue load, extend durability, and are race-legal — many first-timers walk aid stations on the Ironman marathon anyway.
- **Cadence:** aim ~170–180 spm; raising cadence ~5–10% (shorter stride) reduces ground-reaction/braking forces and load on knee and hip — a cheap injury-prevention lever. The FR965 displays real-time cadence.
- **Tissue-specific watch points:** Achilles/calf → load tendons gradually, don't spike hills/speed together; shin (medial tibial stress) → cap weekly increases, check footwear/surface; knee (PFPS/ITB) → cadence + hip-strength; hip/back → core and glute strength, avoid sudden long-run jumps. **Pain that alters gait or persists >24–48 h = back off.**
- Surfaces: rotate softer surfaces; deload after any 2-grade pain (0–10 scale, keep ≤3).

**Run frequency over volume** for durability: 3–4 shorter runs beat 2 long ones for adaptation at lower injury cost early on.

### 3.2 Bike — can progress faster than running

- **Lower impact → faster, larger progressions** are tolerable. The bike is where most Ironman time is spent, so it carries the most volume.
- **FTP (Functional Threshold Power):** the ~1-hour max sustainable power; the anchor for all power zones, IF, and TSS. Test via 20-min test (×0.95) or ramp test. Re-test ~every 6–8 weeks.
- **Power zones (% FTP):** Z1 Recovery <55 · Z2 Endurance 56–75 · Z3 Tempo 76–90 · Z4 Threshold 91–105 · Z5 VO₂ 106–120 · Z6 Anaerobic >120.
- **Ironman race power ≈ 68–78% FTP** (lower for less-trained/longer finish times). Train to *hold that power efficiently*, not to maximize peak FTP.
- **Long-ride structure:** mostly Z2 (60–75% FTP) for aerobic base + fat oxidation + fueling practice. In Build, embed **sub-threshold blocks** (e.g., 3×20 or 2×30 min at 88–94% FTP) — big aerobic stimulus at lower recovery cost than VO₂ work. A full-IM bike leg ≈ **250–320 TSS**; long rides build toward 5–6 h in Peak.
- Quality bike sessions: ~2/week is plenty alongside running and strength.

### 3.3 Swim — technique-first for adult-onset swimmers

- **Technique is the limiter, not fitness.** Adults gain more from stroke efficiency (body position, catch, rotation, breathing) than from hard intervals. Drill-heavy early.
- **CSS (Critical Swim Speed)** = sustainable ~1500 m / threshold pace ≈ lactate-threshold pace.
  - **Test:** time-trial **400 m** and **200 m** in one session. `CSS pace (per 100m) = (T400 − T200) / 2`. (m/s form: `CSS = 200 / (T400 − T200)`.)
  - **Train by CSS:** below CSS (−10 to −15 s/100m) = aerobic/technique/long swims; at CSS = threshold sets (e.g., 200–400 m reps, short rest); above CSS (+5–10 s/100m faster) = short speed reps (50–100 m, longer rest).
  - **Re-test every 6–8 weeks.**
- **Weekly structure (3 swims/week ideal):** (1) **CSS/threshold** session, (2) **technique/drills** session, (3) **open-water skills** (sighting, straight-line, drafting, mass-start tolerance). Add a long continuous swim as IM approaches.
- Beginners: prioritize being **comfortable and efficient for 3.8 km**; speed is secondary.

*Sources: [JOSPT — Running distance progression & injury](https://www.jospt.org/doi/10.2519/jospt.2014.5164), [Canadian Running — 10% rule / single-run spikes (BJSM)](https://runningmagazine.ca/sections/training/the-10-per-cent-mileage-rule-isnt-what-you-think-study-warns/), [BestBikeSplit — FTP guide](https://www.bestbikesplit.com/functional-threshold-power-cycling-triathlon), [Roadman — FTP for triathletes](https://roadmancycling.com/blog/ftp-training-for-triathletes), [TrainingPeaks — CSS training](https://www.trainingpeaks.com/blog/how-to-use-critical-swim-speed-training/), [Steel City — CSS](https://steelcityendurance.com/swimming/critical-swim-speed-css-and-total-immersion-swimming/)*

## 4. Brick Workouts & Transition Training

**Purpose:** train the **bike→run transition** (and occasionally swim→bike). Running off the bike is a distinct skill: the body must reroute blood from cycling muscles to running muscles, and adapt motor patterns (the "jelly legs"). Bricks also build mental confidence and let you rehearse fueling and T2 logistics.

**Frequency:** ~**1 brick/week**, especially in Build/Peak. Beginners start with one; advanced athletes can make most rides bricks. Don't over-do high-intensity bricks — they are costly.

**Run-off-the-bike duration:** **20–60 min** is the sweet spot (shorter doesn't teach the adaptation). Build toward IM-relevant durations in Peak (e.g., 4–5 h ride + 30–45 min run).

| Phase | Example brick |
|---|---|
| Base | 90 min Z2 bike → 15–20 min easy run (just teach the legs) |
| Build | 2.5–3 h bike w/ race-power blocks → 30–40 min run at IM run pace |
| Peak | 4–5 h bike at IM power (fueling at race rate) → 30–45 min run, hold form & pace |

Also practice **transitions** physically: a small T1/T2 station, gear order, wetsuit strip, helmet-before-bike, etc.

*Sources: [TrainingPeaks — Brick workouts](https://www.trainingpeaks.com/blog/using-brick-workouts-in-triathlon-training/), [USA Triathlon — Brick workouts](https://www.usatriathlon.org/articles/training-tips/how-to-use-brick-workouts-in-triathlon-training), [Triathlete — Brick workout](https://www.triathlete.com/training/get-to-know-the-brick-workout/)*

## 5. Concurrent Training / Interference Effect

### 5.1 The evidence

- **Interference is real but manageable.** Hickson (1980): concurrent strength+endurance initially improved both, but **strength gains plateaued/declined** after ~7 weeks while aerobic gains were preserved. Endurance interferes with strength/hypertrophy more than the reverse.
- For triathletes, the **benefits of strength outweigh the interference** when programmed well: better economy, fatigue resistance, injury reduction, and durability late in long races.
- **Endurance *intensity* does not strongly mediate the interference** to maximal lower-body strength in short-term concurrent training — i.e., it's mostly about **fatigue, proximity, and total load**, not whether the endurance was Z2 vs hard.

### 5.2 Sequencing & weekly placement (how to avoid compromising key sessions)

| Rule | Why |
|---|---|
| **Strength *before* endurance** (within a day) favors strength adaptation; **endurance before strength** favors endurance. Choose by the day's priority. | Sequence shifts which quality is protected. |
| **Separate heavy lower-body lifting from the long run/long ride by ≥24 h (ideally ~24–48 h).** Never do heavy legs the day before (or same day as) a key long run. | DOMS + fatigue wreck the key endurance session and raise injury risk. |
| **Keep ≥48 h between two strength sessions.** | Recovery distribution. |
| **On hard-interval days:** do strength *after* the intervals if same-day; on easy Z1/Z2 days, either order is fine. | Protect the quality endurance stimulus. |
| **"Hard days hard, easy days easy."** Pair strength with already-hard days to keep easy days truly easy. | Preserves polarized distribution and recovery days. |
| **Schedule the final pre-race strength session ≥72 h before the race**; remove heavy lower-body work in race week. | Avoid residual fatigue/DOMS on race day. |

### 5.3 How strength changes across the season

| Season phase | Strength emphasis | Frequency |
|---|---|---|
| Prep/Base | **Build phase: anatomical adaptation → max strength** (heaviest lifting of the year) | 2×/wk |
| Build | **Maintenance** — fewer sets, hold the gains, protect endurance quality | 1–2×/wk |
| Peak | **Maintenance, reduced** | 1×/wk |
| Race week / Taper | Drop heavy work; optional light movement; last real session ≥72 h out | 0–1× |

So: **more (and heavier) strength in Base; maintenance in Build/Peak; taper it out before the race.**

*Sources: [TrainingPeaks — Risks of concurrent training](https://www.trainingpeaks.com/blog/risks-of-concurrent-training/), [PMC — Strength/endurance sequence & endurance performance](https://pmc.ncbi.nlm.nih.gov/articles/PMC11359207/), [PMC — Endurance intensity & interference to strength](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5093324/), [Altabrio — Concurrent training for triathletes](https://altabrio.com/concurrent-training-bridging-the-gap-between-strength-and-endurance-for-the-triathlete/), [8020 Endurance — Strength scheduling](https://www.8020endurance.com/incorporating-strength-training-into-your-training-plan/)*

## 6. Strength Programming for Endurance Athletes

### 6.1 Principles
- **Lift heavy, low volume, multi-joint.** Goal is **neuromuscular force/economy**, not hypertrophy or "the burn." Keep sessions short (~25–50 min). Research consensus: **2 × ~25-min effective lifts/week** is the endurance-athlete sweet spot.
- Progression across the year: **higher reps early (general prep) → heavier/lower reps for max strength → maintenance.**

### 6.2 Set/rep schemes

| Quality / phase | Sets × reps | Load | Rest |
|---|---|---|---|
| **Anatomical adaptation** (early Base) | 2–3 × 8–12 | ~light–moderate | 60–90 s |
| **Max strength** (Base) | 3–6 × 3–6 (keep total reps low, ~<20 working reps) | ≥80% 1RM | 2–5 min |
| **Maintenance** (Build/Peak) | 2–3 × 6–12 | moderate–heavy | 90 s–3 min |

### 6.3 Key lifts (for triathlon)
- **Lower body (priority):** back/front squat, deadlift/Romanian deadlift, split squat/lunge, hip thrust, step-up, calf raise (Achilles resilience).
- **Upper body / pull:** for swim — pull-ups/lat work, rows, overhead press, push-ups.
- **Core / trunk:** planks, dead-bug, Pallof press, anti-rotation, bird-dog — for posture/economy and back health on the bike/run.
- **Mobility:** hips, ankles, thoracic spine — supports aero position and run mechanics.

### 6.4 Tapering strength near the race
- Reduce **sets and load** progressively across the final weeks; **last full session ≥72 h before race day.** Remove heavy eccentric/lower-body work in race week to avoid DOMS. Keep neural sharpness with light, low-volume movement only if desired.

*Sources: [TrainingPeaks — Heavy lifting for endurance athletes](https://www.trainingpeaks.com/blog/heavy-lifting-for-endurance-athletes/), [TrainingPeaks — Heavy lifting Part 2 scheduling](https://www.trainingpeaks.com/blog/heavy-lifting-for-the-endurance-athlete-part-2-scheduling/), [Kinesis Integrated — Sets/reps for endurance athletes](https://www.kinesisintegrated.com/education/understanding-sets-reps-and-strength-qualities-for-endurance-athletes), [8020 Endurance](https://www.8020endurance.com/incorporating-strength-training-into-your-training-plan/)*

## 7. Recovery & Load-Management Metrics

### 7.1 The Performance Management Chart (PMC): CTL / ATL / TSB

All three derive from **TSS** (Training Stress Score = duration × intensity relative to threshold, from power, pace, or HR; an IM bike leg ≈ 250–320 TSS).

| Metric | Meaning | Time constant | Interpretation |
|---|---|---|---|
| **CTL** (Fitness) | Exponentially-weighted avg daily TSS | **42 days** | Long-term fitness; raise it gradually |
| **ATL** (Fatigue) | Exponentially-weighted avg daily TSS | **7 days** | Recent fatigue; when ATL > CTL you're accumulating fatigue |
| **TSB** (Form) | **CTL − ATL** (yesterday's values) | — | "Freshness." Negative = fatigued/building; positive = fresh |

**TSB reference ranges:**
| TSB | State |
|---|---|
| **+15 to +25** | Race-ready / peaked (some fitness decay if held long) |
| **−10 to −30** | Productive training "grey-to-overload" zone |
| **< −30** | Excessive strain → take consecutive easy/rest days |

### 7.2 Ramp rate (CTL growth/week) — safety guardrail

| Ramp (CTL pts/wk) | Verdict |
|---|---|
| **3–5** | Conservative, sustainable — **default for this amateur** |
| **5–7** | Aggressive but OK for experienced, well-recovering athletes |
| **7–10** | High risk — only for the well-adapted / training camps |
| **>10** | Red flag — overtraining/illness/injury risk climbs steeply |

### 7.3 HRV-guided training (morning metrics)
- **Measure on waking** (Garmin does this overnight). HRV upon waking is most sensitive to training load; later readings are noisier.
- **Higher HRV = better recovered**; persistently **low HRV = chronic stress/under-recovery.**
- Best practice combines **HRV + resting HR (RHR) + subjective wellbeing** — multi-metric beats HRV alone (Nature/Sci Reports 2025). Track **trends and 7-day baselines**, not single days.
- RHR: a morning RHR **elevated ~5–7+ bpm** above baseline signals fatigue, under-recovery, or oncoming illness.

### 7.4 Deload cadence & triggers
- **Default rhythm: 3:1** (3 load weeks : 1 recovery week). For **masters/older or higher-stress athletes use 2:1** (recovery every 3rd week).
- A deload = **reduce volume and especially intensity** (~40–50% volume, keep it easy); it is *not* total rest. Lets the body absorb adaptation.
- **Trigger an unplanned deload** when ≥2 of: HRV trending down for days, RHR up 5–7+ bpm, performance stagnant/declining, lingering soreness >48 h, joint aches accumulating, sleep poor, motivation gone, TSB < −30.

*Sources: [TrainingPeaks — Coach's guide to ATL/CTL/TSB](https://www.trainingpeaks.com/coach-blog/a-coachs-guide-to-atl-ctl-tsb/), [Paincave — CTL/ATL/TSB](https://www.paincave.io/blog/ctl-atl-tsb-explained), [TrainingPeaks — Morning metrics](https://www.trainingpeaks.com/blog/the-metrics-athletes-should-track-every-morning/), [Nature Sci Reports 2025 — HRV/RHR/wellbeing training](https://www.nature.com/articles/s41598-025-13540-z), [Kubios — HRV-guided training](https://www.kubios.com/blog/hrv-guided-training/), [Scientific Triathlon — beginner structure/deloads](https://scientifictriathlon.com/beginner4/), [TrainerRoad — recovery week cadence](https://www.trainerroad.com/blog/new-triathlon-and-masters-triathlon-plans/)*

## 8. Daily Readiness Decision Logic

A rule-based framework an AI coach can follow each morning. **Modify intensity first, then volume, then rest** — protect the *key* session of the day; sacrifice the optional/easy ones.

### 8.1 Inputs (from FR965 + athlete check-in)
- HRV status (Balanced / Unbalanced-Low / Unbalanced-High / Poor), morning RHR vs baseline, **Training Readiness** score (1–100), **Body Battery** at wake, sleep score & hours, subjective: legs (fresh/heavy), motivation, soreness, pain (0–10), stress/life load, TSB.

### 8.2 Simple scoring approach (0–10 readiness score)
Start at 10, subtract for each flag:

| Flag | Penalty |
|---|---|
| Sleep < 6 h OR sleep score < 50 | −2 |
| RHR elevated ≥7 bpm over baseline (≥5 = −1) | −2 |
| HRV status "Unbalanced-Low" / clearly below baseline | −2 |
| Body Battery < 30 at wake / Training Readiness < 25 | −2 |
| Heavy legs / soreness lasting >48 h | −1 |
| Low motivation / high life stress | −1 |
| **Pain that alters gait or is ≥4/10** | **auto-cap to "rest/cross-train", overrides score** |

### 8.3 Decision tree

```
PAIN ≥4/10 or gait-altering?
   → YES: No running. Rest or non-impact aerobic (easy swim/spin) if pain allows. Flag for assessment.
   → NO: continue ↓

Compute readiness score (8.2).

Score 8–10  (GREEN / Training Readiness High-Prime, Body Battery high):
   → Proceed as planned. Good day for the week's KEY hard or long session.

Score 5–7   (AMBER):
   → Keep the session but REDUCE INTENSITY first:
       - Hard/interval planned → convert to Z2 endurance or drop to lower zone / fewer reps.
       - Long session planned → keep it but shorten ~20–30% and keep strictly easy.
       - Strength planned → drop to maintenance volume or skip heavy lower body.

Score 3–4   (ORANGE / Readiness Low):
   → REDUCE VOLUME too: short easy aerobic only (30–45 min Z1–Z2), technique/mobility, or full active recovery. No quality.

Score 0–2   (RED / Readiness Poor, HRV Poor, RHR way up, sick):
   → REST or complete day off. If illness symptoms below the neck or fever → no training.
```

### 8.4 Conflict-resolution rules
- **HRV vs feel:** if HRV/RHR are red but the athlete feels great, allow easy training, **defer the hard session** 1 day.
- **One bad night** in isolation (otherwise good trend) → proceed but don't add intensity.
- **Two consecutive red mornings** → insert an unplanned recovery day/deload.
- **Never make up missed hard sessions** by stacking them; let them go.
- Re-evaluate Training Readiness/Body Battery again pre-session if hours have passed.

*Sources: [TrainingPeaks — Using HRV to schedule intensity](https://www.trainingpeaks.com/blog/using-heart-rate-variability-to-schedule-the-intensity-of-your-training/), [Kubios — HRV-guided training](https://www.kubios.com/blog/hrv-guided-training/), [Garmin FR965 — Training Readiness manual](https://www8.garmin.com/manuals/webhelp/GUID-0221611A-992D-495E-8DED-1DD448F7A066/EN-US/GUID-C21BE0C8-A08E-4DA1-B6C6-2E0E2DDDB372.html)*

## 9. Nutrition & Fueling (High Level)

### 9.1 Long sessions & race day — carbohydrate
- **Carbs/hour, bike:** typical IM range **70–90 g/h** (some absorb up to ~120 g/h). Field data: IM athletes average ~**90–96 g/h on the bike**, with wide individual variation (37–130 g/h).
- **Carbs/hour, run:** lower tolerance — **50–80 g/h** (mechanical + heat stress reduce gut absorption).
- **Dual-source carbs (glucose:fructose ~2:1)** use two intestinal transporters → enables ~90 g/h+ without as much GI distress.

### 9.2 Hydration & sodium
- Start ~**500 ml fluid/h** on the bike; adjust for heat, body size, sweat rate (and sodium losses). **Carbs are only absorbed if hydration/sodium are adequate** — fueling and hydration are inseparable.

### 9.3 Periodized / "train the gut"
- **Gut is trainable.** Start long-session fueling at **40–50 g/h**, add **5–10 g/h per week** until reaching race target. Practice race nutrition in **Peak long rides/bricks** at race intake rate.
- **Periodize fueling to the session:** fuel high for key/long/quality sessions; some easy short sessions can be done lower-carb for metabolic flexibility — but **don't under-fuel key or long days** (risk: RED-S, poor adaptation, injury).
- Bike vs run need different strategies (gels/drink on bike with more volume; on run, smaller, more frequent, less concentrated).

*Sources: [NutritionTriathlon — IM race fueling](https://www.nutritiontriathlon.com/blog/ironman-nutrition-a-practical-guide-to-fueling-race-day-performance), [Precision Hydration — IM fueling/hydration](https://www.precisionhydration.com/performance-advice/nutrition/dougal-allan-ironman-fueling-nutrition-hydration-strategy/), [Triathlete — high-carb pro fueling](https://www.triathlete.com/nutrition/race-fueling/ironman-world-championship-pros-high-carb-nutrition-plans/), [NEVERSECOND — IM fuel guide](https://never2.com/blogs/guides/ironman-fuel-and-hydration-guide)*

## 10. Taper Strategy (Final 2–3 Weeks)

- **Duration:** ~**14 days** standard for full IM (some athletes benefit from up to ~21).
- **Volume:** cut **40–60%** vs pre-taper, following an **exponential decay** (sharp early drop, leveling toward race day) — not a linear slide.
- **Intensity:** **maintain the proportion** of high-intensity work (if 20% was hard pre-taper, keep ~20% within the smaller volume). Include short **race-pace efforts ~every 72 h** to stay sharp neuromuscularly.
- **Frequency:** keep sessions frequent — **reduce frequency ≤20%, if at all.** Shorten sessions rather than deleting them (preserves swim/run motor patterns).
- **Last big session ~2 weeks out** (e.g., race-pace bike + brief brick run); after that, everything trends down.
- **Strength:** last real lift **≥72 h** before race; no heavy lower body in race week.
- **Goal:** TSB rising into **~+15 to +25** on race day — fresh, sharp, not detrained.

> Caveat: there is **no IM-specific RCT** on tapering; the above is best-practice extrapolation from shorter-distance research + coaching consensus.

*Sources: [Scientific Triathlon — Tapering](https://scientifictriathlon.com/tapering-for-triathlon/), [Triathlete — Taper for IM/70.3](https://www.triathlete.com/training/how-to-taper-for-ironman-703/), [PMC — Taper meta-analysis](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10171681/)*

## 11. Typical Weekly Hours & Session Counts (Amateur with a Job)

Balancing a full-time job, a realistic ceiling is **~12–16 h/week at peak**. Sessions per week typically **9–12 + 1 rest day**.

| Phase (months) | Hours/wk | Swim | Bike | Run | Strength | Brick | Notes |
|---|---|---|---|---|---|---|---|
| **Base 1–2** (1–6) | 6–10 | 2–3 | 2–3 | 3 | 2 | 0–1 | Technique + Z2; gym max-strength block |
| **Base 3** (7–9) | 8–11 | 3 | 3 | 3 | 1–2 | 1 | Biggest pure aerobic base |
| **Build** (10–15) | 9–14 | 3 | 3 | 3–4 | 1–2 | 1 | Race-specific intensity; 70.3 rehearsal |
| **Peak** (16–17.5) | 12–16 | 2–3 | 3 | 3 | 1 | 1 | Long ride 5–6 h, long run 30–35 km, big bricks; back-to-back weekend long sessions |
| **Taper** (final 2–3 wk) | 4–7 | 2–3 | 2–3 | 2–3 | 0–1 | 0–1 | Volume −40–60%, intensity held |

A representative peak week: 2 swims, 3 rides (incl. 1 long + 1 sub-threshold), 3 runs (incl. 1 long + 1 quality), 1 brick, 1 strength, 1 rest day. **Long sessions on the weekend** (job constraint); **quality on 2 weekdays**; remaining weekdays easy/recovery/technique.

## 12. Garmin Forerunner 965 — Data & Coaching Use

### 12.1 Metrics and how each informs coaching

| Metric | What it is | Coaching use |
|---|---|---|
| **Training Readiness** (1–100) | Composite of sleep score, recovery time, **HRV status, acute load, sleep history (3 nights), stress history (3 days)** | **Primary daily go/no-go signal.** Map to §8 score. Prime/High → key sessions OK; Low/Poor → reduce or rest. |
| **HRV Status** (Balanced / Unbalanced / Low / Poor) | Overnight HRV vs personal 7-day & long-term baseline | Trend-based fatigue gauge. Unbalanced-Low or Poor → de-prioritize intensity, watch for illness/overreach. |
| **Body Battery** (0–100) | Energy reserve from HRV, stress, sleep, activity | Wake value gauges readiness; low at wake → easier day. Watch drain/recharge pattern. |
| **Training Status** | Fitness trend from VO₂max change + acute load + HRV status (Productive, Maintaining, Peaking, Overreaching, Unproductive, Detraining, Recovery) | Validates whether the block is "working." Overreaching/Unproductive → deload; Productive → continue. |
| **VO₂max** | Estimated aerobic capacity (run & bike) | Long-term fitness trend; rising = base is building. Don't chase day-to-day noise. |
| **Training Load (Acute / Chronic) & Load Focus** | 7-day acute load; chronic load; aerobic-low/high/anaerobic split | Garmin's analog to ATL/CTL; Load Focus shows if you're missing high-aerobic or anaerobic stimulus. Use to balance polarized distribution. |
| **Resting HR** | Overnight/morning RHR + trend | Elevated ≥5–7 bpm vs baseline = under-recovery/illness flag (§7.3). |
| **Sleep score & stages** | Duration + quality | Feeds readiness; chronic poor sleep → reduce load. |
| **Real-time HR zones, cadence, power (w/ pedals/HRM), pace, Training Effect (aerobic/anaerobic)** | In-session | Enforce zone discipline (keep easy easy), monitor cadence ~170–180, verify session hit its intended stimulus. |
| **Recovery Time** | Hours until recovered | If a hard/long session is planned but recovery time is still high → adjust. |

> Practical caveat: Garmin's optical-wrist HRV/RHR and VO₂max are **estimates** — trust **trends over absolute values**, and corroborate with subjective check-ins (the multi-metric approach in §7.3/§8). A chest strap improves HR/HRV accuracy for key sessions.

### 12.2 Getting data OUT of Garmin into a local Mac app

| Method | What it gives | Pros | Cons |
|---|---|---|---|
| **FIT file export** (per-activity, via Garmin Connect web/USB, or `garminexport`/`garmin-backup`) | Raw activity files (FIT/TCX/GPX/CSV) | Official format; full per-second data; works offline once exported; Garmin **FIT SDK** (incl. Python) to parse | Per-activity; doesn't include daily wellness metrics (HRV status, Body Battery, Training Readiness) by default; manual unless scripted |
| **`python-garminconnect`** (cyberjunky, unofficial) | 130+ endpoints: activities (incl. **FIT**), **HRV, RHR, Body Battery, sleep, stress, training status/readiness**, etc.; tokens cached at `~/.garminconnect/` | Pulls the **wellness/readiness metrics** FIT files lack; pure local Python; auto-refresh OAuth | **Unofficial** — can break on Garmin changes; ToS gray area; rate-limit/credential risk; no SLA |
| **Apple HealthKit bridge** (Garmin Connect → Apple Health sync, then read HealthKit on Mac/iOS) | HR, HRV (as SDNN, not Garmin's "status"), workouts, sleep, RHR | First-party Apple API; stable; user-consented; good on Apple platforms | Garmin→Health sync is partial (**no Body Battery / Training Readiness / Training Status**); HealthKit primarily iOS (Mac access limited); lossy vs native Garmin metrics |
| *(Reference only)* **Official Garmin Health/Connect Developer API** | Sanctioned data access | Stable, ToS-clean | Requires partner approval — impractical for a personal local app |

**Recommendation for this app:** primary = **`python-garminconnect`** for daily wellness/readiness + activity metrics (it's the only practical route to HRV status / Body Battery / Training Readiness / Training Status), with **FIT export + FIT SDK** as a robust fallback for full activity detail. Treat the unofficial API as fragile: cache locally, handle auth failures gracefully, and don't store raw credentials.

*Sources: [Garmin FR965 manual — Training Readiness](https://www8.garmin.com/manuals/webhelp/GUID-0221611A-992D-495E-8DED-1DD448F7A066/EN-US/GUID-C21BE0C8-A08E-4DA1-B6C6-2E0E2DDDB372.html), [Garmin FR965 manual — Training Status](https://www8.garmin.com/manuals/webhelp/GUID-0221611A-992D-495E-8DED-1DD448F7A066/EN-US/GUID-44C7BB4B-EFF7-4A42-AC03-8A6AABB94807.html), [DC Rainmaker — FR965 review](https://www.dcrainmaker.com/2023/03/garmin-forerunner-965-depth-review.html), [python-garminconnect (GitHub)](https://github.com/cyberjunky/python-garminconnect), [garminexport (PyPI)](https://pypi.org/project/garminexport/), [Garmin FIT SDK](https://developer.garmin.com/fit/)*

## 13. Practitioner & Sports-Science Insights (from expert podcasts/videos)

The transcripts in [`research/deep-dive-coaching/youtube-transcripts/`](deep-dive-coaching/youtube-transcripts/) add elite-coach and researcher detail that extends the sections above. Paths below are relative to that folder.

### 13.1 Intensity control & the "Norwegian method" (extends §2)

- **The real "secret" is disciplined easy days, not extreme volume.** Arild Tveiten (coach of Blummenfelt/Iden) notes 1990s Ironman pros trained 40–45 h/week — *more* than his squad; the edge is strict intensity control. Easy days are genuinely easy (lactate ~1 mmol/L, no pace target); their lactate-controlled threshold sessions sit at **~2.5–3 mmol/L — notably below the classic 4-mmol convention** — because the goal is the highest output still aerobic, sparing glycogen for the run. Discipline compounds: visiting athletes who go slightly too hard on both easy and hard days look great in week 1, then crack by weeks 2–3 ([Tveiten](deep-dive-coaching/youtube-transcripts/scientific-triathlon-arild-tveiten-norwegian-method.md)).
- **Lactate is used to calibrate feel and steer each athlete's metabolic trend.** Iden and Blummenfelt run the *same* program with individualized endings (one extends threshold, the other adds surges) because they drift in opposite directions; athletes are taught *why* each session exists so they can self-adjust ([Iden/Blummenfelt](deep-dive-coaching/youtube-transcripts/rich-roll-iden-blummenfelt-norwegian-method.md)).
- **Corroborates §2's grey-zone warning.** Sitko: a simple 3-zone model performs as well as elaborate schemes, and there's no evidence that (e.g.) 210 W vs 260 W within the same zone 2 produces different long-term adaptations ([Sitko — evidence-based training](deep-dive-coaching/youtube-transcripts/scientific-triathlon-evidence-based-training-cycling-triathlon.md)). **VLamax** is worth knowing: higher suits short-course punch but burns more glycogen (needs more race carbs), lower for long distance ([Tveiten](deep-dive-coaching/youtube-transcripts/scientific-triathlon-arild-tveiten-norwegian-method.md)).

### 13.2 Periodization models & taper in practice (extends §1, §10)

- **No periodization model has strong evidence** (Sitko, Mujika, Schmidt-Wendling all converge): two Olympic rowing golds were won four years apart on completely different intensity distributions; the only consistent finding is that elites spend most time easy. Mujika frames periodization as a *dynamic* logical sequence, not a fixed template — for a two-peak age-group season he'd run traditional periodization twice, switching to block/reverse only if progress stagnates ([Mujika](deep-dive-coaching/youtube-transcripts/scientific-triathlon-mujika-tapering-periodisation-recovery.md)). Schmidt-Wendling goes further, planning only ~1 week ahead with a flexible year plan ([Schmidt-Wendling](deep-dive-coaching/youtube-transcripts/scientific-triathlon-mario-schmidt-wendling-long-distance.md)).
- **Taper evidence (Mujika's meta-analysis) directly backs §10:** cut volume 50–60% vs the prior mesocycle, *maintain* intensity and frequency, ideal duration 10–14 days, progressive (exponential/linear) decay beats a step taper. Key nuance: ideal taper duration is set by the individual's adaptation/de-adaptation profile — **not** fiber type or race distance. Judge the taper by benchmark sessions and RPE-at-output *during* the taper, not only race day; match energy intake to the reduced load ([Mujika](deep-dive-coaching/youtube-transcripts/scientific-triathlon-mujika-tapering-periodisation-recovery.md)).

### 13.3 Training load — dose within life context (extends §7, §11)

- **Weekly hours are not the barometer.** Dixon's age-group World Champs qualifiers average ~10–12 h/week, but that's the optimal dose *in their life context*, not proof less is better (his pros did 18–30 h). Each week has only 1–3 "needle-moving" key sessions to protect; the rest is flexible filler you move rather than cram ([Dixon](deep-dive-coaching/youtube-transcripts/trainingpeaks-matt-dixon-training-loads-non-negotiables.md)) — the same logic as §11's "quality on 2 weekdays, protect the long sessions."
- **Amateurs shouldn't copy pro context.** Sitko: chasing pro CTL (155–160) around a job burns you out; and elite case studies surprise — 5 Grand Tour podium finishers averaged under 17 h/week and 3 of 5 did *no* gym strength work ([Sitko](deep-dive-coaching/youtube-transcripts/scientific-triathlon-evidence-based-training-cycling-triathlon.md)). Eriksson warns against over-specificity — develop the underlying qualities (threshold, VO₂max) rather than always training race-specific ([Eriksson](deep-dive-coaching/youtube-transcripts/human-endurance-mikael-eriksson-getting-faster.md)). Skiba: individual response is huge (2 weeks of the same block gave one cohort ~10% VO₂max / ~15% CP gains while he himself, a subject, didn't move) — analyze every athlete individually ([Skiba](deep-dive-coaching/youtube-transcripts/scientific-triathlon-skiba-endurance-training-science.md)).

### 13.4 Strength training — assessment & execution (extends §5, §6)

- **"If you don't assess, it's just a guess" (Brodie).** Layer the assessment: posture → movement screen (overhead squat, hinge, single-leg hip lift) → sport video *at race pace* (trained runners are efficient mainly at race pace, so easy-pace video hides problems) → only later a weighted 5–8–10RM. Never test true 1RMs; 3RMs rarely (they don't reflect endurance demands) ([Brodie part 2](deep-dive-coaching/youtube-transcripts/scientific-triathlon-brodie-strength-training-part2.md)).
- **Session design corroborates §6:** breathing work first (doubles as a rehearsed race-morning calming routine), then a power move, then the athlete's biggest weakness, hard core finisher (side plank with top foot *forward* to hit all oblique compartments); prefer hinges over deep squats, sumo deadlift off blocks (triathletes needn't pull from the floor). Strength sessions should feel RPE 5–7 — "walk out feeling you could do one more set"; going as hard as swim/bike/run is the most common error ([Brodie part 1](deep-dive-coaching/youtube-transcripts/scientific-triathlon-brodie-strength-training-part1.md), [part 2](deep-dive-coaching/youtube-transcripts/scientific-triathlon-brodie-strength-training-part2.md)). Consistency matters: tissue stiffness is lost fast when you stop — Brodie discounts inconsistent history by a third when estimating strength-training age.
- **Manage energy systems, not just muscles (refines §5.2, §6.4):** in-season, lift *heavy* in sets of 2–3 with long rests (CP/neural, minimal lactate — pro cycling teams lift even the day before a Grand Tour TT) rather than "light weight, high reps." For long-course athletes with high VLamax, limit explosive/glycolytic lifting in the final months. Mujika independently endorses strength work as the single best injury-prevention tool plus an economy gain — 3–4 sport-relevant exercises, 1–2 sets, twice weekly to build, once to maintain ([Mujika](deep-dive-coaching/youtube-transcripts/scientific-triathlon-mujika-tapering-periodisation-recovery.md)).

### 13.5 Injury prevention (extends §3.1)

- **Most triathlon injuries are overuse from load spikes** — swimmer's shoulder, knee pain (often from weak glutes / hip drop, not the knee itself), and tibial stress fractures (common in swim/bike-background athletes unadapted to run impact). Prevent with gradual load progression, glute activation, technique, footwear, and vitamin D; heed early "niggles" ([GTN — 5 common injuries](deep-dive-coaching/youtube-transcripts/gtn-prevent-5-common-triathlon-injuries.md)). This is direct practitioner support for §3.1's "cap single-session spikes" and "knee → cadence + hip strength."
- **IT-band syndrome specifics:** it's a repetitive-overuse injury; stretching/foam-rolling/massaging the band is only palliative — durable resolution comes from strengthening the hip/glute muscles that control the knee (side-lying hip abduction, unilateral bridge, banded clam), with emphasis on control and progression over load ([Apex Rehab — IT band](deep-dive-coaching/youtube-transcripts/apex-rehab-it-band-syndrome-strengthening.md)).

### 13.6 Detraining time-course (new — informs §7, off-season, injury layoffs)

Mujika's meta-analysis: blood volume (→ stroke volume → VO₂max) drops almost immediately on stopping; within ~4 weeks an elite shows a miniature metabolic syndrome; neuromuscular qualities decay from ~3 weeks (fiber diameter, neural impulse velocity). Countermeasures during injury/breaks: reduced training with *retained intensity*, *similar-mode* cross-training only (cross-country skiing helps a runner; rock climbing doesn't), cross-education (train the healthy limb to protect the injured one), even motor imagery. Post-Ironman, elite blood markers normalize in 5–8 days ([Mujika](deep-dive-coaching/youtube-transcripts/scientific-triathlon-mujika-tapering-periodisation-recovery.md)).

## Coaching Rules Summary (If-Then)

**Periodization & structure**
- IF planning the 18 months → THEN Year 1 = foundation (durability, swim technique, max-strength), Year 2 = IM-specific build; sequence Base→Build→Peak→Taper; insert B-race (sprint/Oly ~mo 5) and 70.3 (~mo 11).
- IF in any block → THEN run **3:1** load:recovery weeks (2:1 if athlete is masters/high-stress).

**Intensity distribution**
- IF programming weekly intensity → THEN ~**80% easy (Z1–Z2) / ~20% hard**; max **2–3 quality sessions/week** total across sports; ≥48 h between hard sessions for the same muscle group.
- IF an "easy" day → THEN keep it genuinely easy (no grey zone); the long ride/run count as key stressors.

**Sport-specific**
- IF progressing the run → THEN cap the **long run vs recent-30-day longest run at ≤~10%**; use cadence ~170–180 and run-walk for beginners; ≤3/10 pain only.
- IF progressing the bike → THEN it can grow faster than running; long rides mostly Z2 (60–75% FTP), add sub-threshold blocks (88–94% FTP) in Build; target IM power 68–78% FTP.
- IF developing the swim (adult-onset) → THEN technique first; train by CSS (400/200 TT), 3 swims = CSS + drills + open-water; re-test CSS every 6–8 wk.

**Bricks**
- IF in Build/Peak → THEN ~1 brick/week, run-off-bike 20–60 min (longer in Peak), practice race fueling + transitions.

**Concurrent strength**
- IF scheduling heavy lower-body lifting → THEN keep it ≥24 h (ideally 24–48 h) from the key long run/ride; never the day before a key long run.
- IF same-day strength + endurance → THEN do strength *before* on strength-priority days, *after* the intervals on hard endurance days; ≥48 h between lifts.
- IF in Base → THEN heaviest max-strength (2×/wk); IF Build/Peak → maintenance (1–2×/wk); last lift ≥72 h before race.

**Strength dosing**
- IF max-strength phase → THEN 3–6×3–6 reps @ ≥80% 1RM, low total volume; IF maintenance → 2–3×6–12.

**Load & recovery**
- IF ramping CTL → THEN target **3–5 TSS/wk** (≤7 max); >10 = stop.
- IF TSB < −30, or ≥2 of {HRV down-trend, RHR +5–7 bpm, perf decline, soreness >48 h, poor sleep, lost motivation} → THEN deload (reduce volume ~40–50% + drop intensity).
- IF racing → THEN aim TSB **+15 to +25** on race day.

**Daily readiness (see §8 tree)**
- IF pain ≥4/10 or gait-altering → THEN no running; rest or non-impact only; flag.
- IF Training Readiness Prime/High & score 8–10 → THEN do the key/hard/long session.
- IF score 5–7 (Amber) → THEN keep session, cut **intensity** first (or shorten long run ~20–30%).
- IF score 3–4 (Orange/Low) → THEN cut **volume** too: easy 30–45 min only, no quality.
- IF score 0–2 (Red/Poor) or sick (fever/below-neck) → THEN rest day.
- IF HRV/RHR red but feel good → THEN easy only, defer the hard session 1 day. IF two red mornings in a row → THEN unplanned recovery day.

**Nutrition**
- IF long/key session or race bike → THEN fuel **70–90 g carb/h** (glucose:fructose 2:1), ~500 ml fluid/h + sodium; run **50–80 g/h**.
- IF building fueling tolerance → THEN start 40–50 g/h, +5–10 g/h per week; rehearse race nutrition in Peak.

**Taper**
- IF final 2–3 weeks → THEN cut volume **40–60%** (exponential decay), **hold intensity proportion**, keep frequency (−≤20%), race-pace touches every ~72 h, last big session ~2 wk out, last heavy lift ≥72 h out.

**Garmin**
- IF reading FR965 each morning → THEN use **Training Readiness** as primary go/no-go, corroborate with **HRV status + RHR trend + Body Battery + sleep + subjective**; trust trends over single values.
- IF building the app's data pipeline → THEN use **`python-garminconnect`** for wellness/readiness metrics (+ FIT export/FIT SDK fallback); treat the unofficial API as fragile (cache locally, handle auth failures).
